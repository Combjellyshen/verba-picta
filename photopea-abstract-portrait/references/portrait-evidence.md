# 人物证据与艺术转译

## 输入归属

严格核验目标人物身份、消息起止范围、发言者归属及材料原始属性（原始对话或摘要整理）。输入材料严格限定于本次目标人物语料，与任务系统指令、历史会话、个人档案及通用模板隔离。归属存疑的内容作为背景上下文参考，排除出核心画像证据链。

内容类型清晰界定为：本人原话、自述／转述、他人评价、引用、虚构、AI 生成及归属不明七类。对 AI 侧写的转发或认可，其证据效力限定为“本人认可该表述”，与经独立核实的事实区分对待；自述性陈述（如“擅长某事”）作为自我认知倾向记录，实际能力推断须依据具体行动过程与可验证结果。

无原生索引的材料依原始序次统一编号（如 `M001`），原生 ID 或时间戳优先沿用。长文本分段与信息合并时，系统核对事件时序、情境演变与潜在反例，二次摘要须追溯至原始发言方可确立为有效证据。

## 共用证据表

每条重要记录至少包含：证据 ID、消息位置、发言者、内容类型、逐字短引文、可观察表达／行为、情境、解释、替代解释、反例 ID、支持程度与理由。

分立原文引注、客观现象观察与逻辑推断层级，优先记录语料明确展现的事实，使推论与直接观察清晰对应。四大框架共享统一证据 ID 索引，基于客观独立事件引用，保持证据链的严谨性。

| 框架 | 回答的问题 | 边界与原则 |
|---|---|---|
| 语言与互动 | 怎样表达、决策、协调、回应，反复谈什么 | 记录客观交互特征；聚焦系统性表达模式，确保推论具备整体代表性 |
| 情境—反应 | 什么条件下反应如何变化 | 横向比对风险度、时间压力、熟悉程度与角色关系；情境边界模糊时标明待定 |
| 大五人格 | 什么倾向可能跨时间或情境持续 | 聚焦展现具备跨情境稳定性的特质；采用质性描述，省略机械填充与量表评分 |
| COM-B | 某行动的能力、机会、动机条件是什么 | 明确界定目标行为、触发情境与实际结果；清晰区分主观意愿、客观能力与潜在动机条件 |

COM-B 框架参考：[Michie 等，2011](https://link.springer.com/article/10.1186/1748-5908-6-42)。本流程旨在为肖像创作建立严谨的质性观察模型，产出结构化的观察见解。

## 支持程度与反例

综合考量信息来源直接性、事件发生独立性、跨情境一致性及反向证据，以定性文本明确陈述支持力度。单次事件评述仅归属于特定情境，多次转述同一事件合并为单一证据样本；语料未提及项如实标记为信息缺口，采用自然审慎的质性结论。

主动检索潜在反例与张力片段。差异显著时提炼情境约束条件（如“高成本决策中反复审慎核验，低成本探索中敏捷推进”）；若张力无法化解，如实并存记录矛盾点并相应下调推断支持度。各项观察遵循证据自然涌现原则。

## 进入画面

在启动艺术家视觉研究前，固化核心人物观察与证据 ID 映射关系。提炼最富表现力的三至四项核心特质进入画面创作（亦可更加凝练）。构图设计可自由权衡不同特质的视觉权重，始终恪守人物真实事实基底。

`core_observations` 记录 `{id, statement, evidence_ids, limitations}`；`visual_interpretation` 记录 `{observation_ids, decision, reason}`。创作基于构图空间、体量比例、色彩冷暖、边缘张力与几何形态进行纯粹视觉探索，灵活构建专属视觉语言。艺术家特有的图腾符号仅作为表现形式借用，与目标人物的心理特征保持单向映射。

交付文档精炼展示核心观察与必要边界说明；完整证据表由专用数据文件独立归档，画布界面专注展现纯粹画作本身。
