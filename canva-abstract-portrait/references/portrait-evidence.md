# 人物证据与艺术转译

## 输入归属

确认目标人物、消息范围、发言者及材料是原始对话还是摘要。不自动并入任务指令、其他会话、个人档案或模板。归属不明只作上下文，不进入核心判断。

内容类型区分：本人原话、自述／转述、他人评价、引用、虚构、AI 生成、归属不明。本人转发或认可 AI 侧写，只支持“认可了描述”，不使描述成为被证实的事实。自述“擅长”不自动证明能力；有行动与结果才讨论表现。

无 ID 的材料按原顺序编号 `M001` 等，有原 ID／时间戳优先使用。长材料可分段，但合并时检查事件重复、时间变化、遗漏及反例，不把摘要当独立证据。

## 共用证据表

每条重要记录至少包含：证据 ID、消息位置、发言者、内容类型、逐字短引文、可观察表达／行为、情境、解释、替代解释、反例 ID、支持程度与理由。

原文、观察与推断分开。不能补语气、动机、因果或行为结果。四框架引用同一 ID；一句话进入多个框架不增强证据。

| 框架 | 回答的问题 | 边界 |
|---|---|---|
| 语言与互动 | 怎样表达、决策、协调、回应，反复谈什么 | 记录可见现象，单独的措辞不能确定人格 |
| 情境—反应 | 什么条件下反应如何变化 | 比较风险、期限、熟悉度、关系与角色；条件缺失保留未知 |
| 大五人格 | 什么倾向可能跨时间或情境持续 | 不强填五维，不给百分位／量表分数；说明稳定性依据 |
| COM-B | 某行动的能力、机会、动机条件是什么 | 先指定行为、情境和结果；意愿不等于能力，未行动不自动等于无动机 |

COM-B 来源：[Michie 等，2011](https://link.springer.com/article/10.1186/1748-5908-6-42)。本流程是创作中的结构化观察，不把聊天侧写写成测量结果。

## 支持程度与反例

依据来源直接性、事件独立性、跨时间／情境一致性及反例，用文字说明支持程度。单次事件通常只支持该次反应，重复转述不是独立样本。没有提到不证明特征缺失。不创造固定次数门槛或精确置信度。

寻找最可能推翻结论的片段。条件能解释差异时改写为条件关系，例如“高成本决定中反复核对，低成本尝试中迅速行动”。解释不了就保留矛盾、降低支持，不笼统包装为“复杂多面”。优势、局限、压力、冲突不强求齐全。

## 进入画面

研究艺术家前固定人物观察及证据 ID；最多三至四项进入创作，允许更少。构图可改变强调的观察，不可为符合风格重写事实。

`core_observations` 存 `{id, statement, evidence_ids, limitations}`；`visual_interpretation` 另存 `{observation_ids, decision, reason}`。通过空间、比例、色彩、边缘和形态关系表达，禁止固定人格配色表。艺术家的符号不是目标人物的心理证据。

交付只需核心观察及必要限制；完整证据另存，画布不放分析报告。
