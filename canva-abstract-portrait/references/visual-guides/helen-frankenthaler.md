# 海伦·弗兰肯塔勒 / Helen Frankenthaler

## 方向与时期

以下为本技能的研究分组，不是艺术生涯的穷尽式或排他分期。默认组有可定位作品；备选组不足三幅时先补足。

- 默认：**1950 年代的浸染色域与线性骨架**（1952–1957）。研究底布参与、色域渗入及稀疏线条，不混作厚涂。 参考组已配齐。
- 备选：**1960 年代丙烯色场**（1963–1966）。比较更明确色场与边缘，不照搬早期颜料表现。 参考组已配齐。
- 备选：**晚期色层与深色组织**（1988）。作为备选入口，补同阶段作品。 当前仅有研究入口或少量例作，切换前补足三至五幅。

## 默认方向的研究与制作提示

以下是本技能的策展与制作建议，须结合本次实际显示的原图校准；不表示已经完成对用户画作或每幅原作的视觉检查。

- **构图与空间**：让大色域与裸露／浅色底形成流动边界，留白穿入主体而不是只在四周留边。
- **形态与肖像**：人物可以通过色域的站立、倾斜或互相容纳出现，不应另贴一张轮廓脸。
- **色彩关系**：比较透明叠色与不相接颜色产生的呼应，不将取样颜色全部等量使用。
- **边缘与肌理**：研究渗染形成的软边、局部积色和线性痕迹；均匀透明度不能替代真实变化。
- **Canva 制作方法**：UI 用大有机色面和局部透明层搭骨架，少量经过统一的边缘肌理辅助；关键色场独立可调。
- **重点修正**：修正果冻状形状、全边同样模糊、互不相干的水彩贴图与留白被装饰填满。
