# 弗朗兹·克莱因 / Franz Kline

## 方向与时期

以下为本技能的研究分组，不是艺术生涯的穷尽式或排他分期。默认组有可定位作品；备选组不足三幅时先补足。

- 默认：**1950 年代黑白结构与笔势**（1950–1955）。白色是被塑造的形体，不能只在白底上画几根黑棒。 参考组已配齐。

## 默认方向的研究与制作提示

以下是本技能的策展与制作建议，须结合本次实际显示的原图校准；不表示已经完成对用户画作或每幅原作的视觉检查。

- **构图与空间**：比较黑形支撑方向、负形通道和画边截断，白色空间具有与黑色同等的构图作用。
- **形态与肖像**：可以让主轴和侧向支撑暗示身体结构，不把笔画拼成汉字或脸谱。
- **色彩关系**：黑白面积和局部灰层比颜色数量更重要；不要默认加一抹红色作焦点。
- **边缘与肌理**：宽笔迹的推进、转折、干边和覆盖须有差异；尖锐末端应有来由。
- **Canva 制作方法**：UI 先铺大黑形，再用白形反向雕刻空间，结合连续宽笔迹和少量局部边缘素材，保留主体分层。
- **重点修正**：修正黑条像矢量栅栏、白区全被动、交叉处突兀以及同款干刷素材反复复制。
